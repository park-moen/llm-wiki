## Overview

해외 개발자 컨퍼런스를 주제와 녹화본 탐색 경로로 정리한 목록이다. 기업·행사 운영 주체·기술 프로젝트가 직접 공개한 자료를 근거로 삼았다. 여기서 신뢰할 수 있는 출처라는 판단은 공식 주체와 발표 자료의 출처를 추적할 수 있다는 뜻이며, 모든 발표의 주장과 효과가 독립적으로 검증됐다는 뜻은 아니다. 추천 우선순위는 학습 목적에 따른 이 문서의 판단이다.

일반적인 개발 기술과 실무 경험을 찾는다면 아래 목록에서 관심 기술을 고르고, AI 활용 방식이 목적이라면 [AI 활용·개발 workflow 컨퍼런스 가이드](ai-development-conferences-and-recordings.md)를 먼저 본다. 행사명에 연결한 대표 URL은 시간이 지나면 다음 연도로 바뀔 수 있으므로, 특정 연도 자료는 아래의 고정 영상·공식 recap과 Raw를 함께 확인한다.

## Kotlin·IntelliJ·Spring을 학습할 때

- **Kotlin 언어와 서버 개발:** [KotlinConf 공식 행사 보관 페이지](https://2026.kotlinconf.com/)에서 Talks를 찾는다. JetBrains의 [Kotlin 백엔드 발표 안내](https://blog.jetbrains.com/kotlin/2025/08/kotlin-on-the-backend-what-s-new-from-kotlinconf-2025/)는 Spring 협업, 서버 생태계와 관련 발표를 정리하고 있어 백엔드 학습의 출발점으로 적합하다. Android만을 위한 행사로 한정하지 않는다.
- **IntelliJ IDEA 활용:** [IntelliJ IDEA Conf 녹화본](https://www.youtube.com/playlist?list=PLPZy-hmwOdEWItbnW5iDHlXLwnq5RTVYi)을 공식 Watch now! 링크로 확인할 수 있다. FAQ는 무료 시청과 YouTube 녹화본 제공을 안내한다.
- **Spring 실무:** [Spring I/O 세션 목록](https://2026.springio.net/sessions/)에서 Spring Boot·JPA·테스트·AI 등 현재 작업과 가까운 주제를 고른다. 공식 소개가 연결하는 [Spring I/O 2025 Talks](https://www.youtube.com/watch?v=cLWFu33kM3E&list=PLe6FX2SlkJdQ8jcbDZSFJWG7CPXMWi_yf)는 이전 행사 녹화본이며, 세션 목록과 영상 공개 여부는 별도로 확인한다.

KotlinConf FAQ는 Keynote Room의 무료 생중계와 나머지 세션의 행사 후 YouTube 업로드를 안내한다. 이 안내를 근거로 개별 녹화본의 현재 업로드 완료나 workshop 전체 공개까지 확인했다고 해석하지 않는다. 일정·시청 조건은 수집한 연도의 공식 안내에 해당한다.

Kotlin·Spring으로 AI 기능을 만드는 쪽이 목적이라면 [AI 활용 가이드의 Kotlin·Spring 항목](ai-development-conferences-and-recordings.md)으로 이어서 본다. 여기의 추천과 영상 경로 확인은 발표 내용·코드의 실행 검증과 구분한다.

## 공개 녹화본으로 바로 시작하기

- [GitHub Universe 2025 공식 재생목록](https://www.youtube.com/playlist?list=PL0lo9MOBetEFKNlPHNouEmVeYeyoyGTXC): GitHub 공식 블로그의 Featured playlists가 연결한다. 현재 행사 사이트의 무료 Virtual 등록과 별개의 이전 행사 자료다.
- [React Conf 2025 공식 recap](https://react.dev/blog/2025/10/16/react-conf-2025-recap): 원문이 [Day 1](https://www.youtube.com/watch?v=zyVRg2QR6LA&t=1067s)과 [Day 2](https://www.youtube.com/watch?v=p9OcztRyDl0&t=2299s) 전체 영상으로 연결한다.
- [Devoxx 공식 YouTube](https://www.youtube.com/@DevoxxForever): Belgium 공식 페이지는 발표를 녹화해 무료로 공개한다고 안내한다. Java·JVM·AI·Cloud·아키텍처를 찾을 때 유용하다.
- [GOTO Conference Sessions](https://gotopia.tech/sessions): 공식 메뉴가 무료 공개 conference session 탐색 경로로 안내한다.
- AI Native DevCon과 AI Engineer의 영상 경로는 [AI 활용 가이드](ai-development-conferences-and-recordings.md)에 모았다.

위 링크는 공식 페이지에 실제로 연결된 시청 경로다. 영상 재생, 자막 언어와 품질, 모든 지역의 접근 가능 여부까지 시험한 결과는 아니다.

## 무료·등록·유료를 구분하는 방법

- 무료 Virtual 등록은 온라인 접근권 안내다. 전 세션이 YouTube에 공개된다는 뜻으로 해석하지 않는다.
- On demand는 나중에 골라 볼 수 있다는 뜻이며, 무료·회원가입 불필요라는 뜻을 포함하지 않는다.
- QCon SF는 녹화본용 Video-Only Pass를 판매하고 계정 로그인을 안내하며, 이 패스로 제공되는 생중계는 없다고 명시한다. 다른 행사나 모든 연도에 이 정책을 일반화하지 않는다.
- AWS re:Invent의 실습·workshop 등 여러 형식과 공개 영상은 동일하지 않다. 소개 페이지에 나오는 모든 활동이 녹화·공개된다고 가정하지 않는다.
- Microsoft Build의 Next Steps 원문은 후속 학습 저장소가 archive 상태라고 안내한다. 과거 실습 자료와 최신 개발 문서의 역할을 구분한다.

## 내 학습 목적에 맞춰 고르기

아래는 수집한 주제를 바탕으로 한 학습 제안이다.

| 목적 | 먼저 살펴볼 자료 |
|---|---|
| AI로 팀의 개발 방식을 개선 | AI Native DevCon·AI Engineer Code Summit |
| RAG·agent 같은 AI 서비스 기능 구축 | AI Engineer World’s Fair, 사용하는 클라우드의 기술 세션 |
| Java·JVM과 백엔드 기술 | Devoxx, KotlinConf의 서버 개발 발표, Spring I/O |
| IntelliJ IDEA 활용 | IntelliJ IDEA Conf |
| 설계·아키텍처·운영 경험 | QCon·GOTO의 문제와 제약을 설명하는 발표 |
| React와 웹 UI 개발 | React Conf, Google I/O의 Chrome 관련 세션 |
| Apple 플랫폼 앱 개발 | WWDC |
| GPU·AI 추론·가속 인프라 | GTC |

브랜드나 조회수만으로 선택하기보다 실제 문제, 적용 조건, 실패 사례와 검증 방법이 공개되어 있는지 살펴본다. keynote로 방향을 파악하고, 구체적인 작업에는 기술 세션과 공식 문서를 함께 쓰는 방법을 권한다.
