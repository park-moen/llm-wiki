# Predefined macOS keymap: development and Git shortcuts

> Source: https://www.jetbrains.com/help/idea/reference-keymap-mac-default.html
> Collected: 2026-09-22
> Published: 2024-03-18

## IntelliJ IDEA's top keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Recent Files | `⌘ E` |
| Reformat Code | `⌘ ⌥ L` |

## Navigate from symbols

| Action | Shortcut |
| --- | --- |
| Go to Declaration or Usages | `⌘ B` |

## Refactorings

| Action | Shortcut |
| --- | --- |
| Rename... | `⇧ F6` |

## Global VCS actions

| Action | Shortcut |
| --- | --- |
| Commit... | `⌘ K` |
| Show Version Control window | `⌘ 9` |
