## 에이전트를 위한 브라우저 SDK

  * Stagehand는 테스트용으로 만들어진 Playwright와 달리 에이전트를 대상으로 하며, TypeScript, Python, Go에 걸쳐 완전한 브라우저 드라이버를 제공함
  * Playwright 스타일 API인 `goto`, `click`, `locator`, `screenshot`을 지원함
    * page 와 locator 문서에서 브라우저 및 요소 API를 확인할 수 있음
    * 기존 자동화 코드를 옮기기 위한 Playwright 마이그레이션 가이드 를 제공함
  * 로컬 실행에는 Chrome 설치가 필요하며, Quickstart 에서 초기 설정을 안내함
## 브라우저와의 왕복 통신을 줄인 v4

  * 기존 구조에서는 클릭이나 입력 같은 동작마다 외부 스크립트와 브라우저 사이를 오가야 하며, 클라우드처럼 둘 사이의 거리가 멀수록 지연이 커짐
  * v4는 브라우저 시작 시 확장 프로그램을 자동으로 불러와 브라우저 내부에서 제어 명령을 처리하도록 구조를 다시 설계함
    * CDP를 없앤 것이 아니라, 별도 실행 환경에서 보내던 명령을 브라우저 안의 확장 프로그램에서 전달하는 방식
    * 여러 동작을 묶는 배치 실행으로 왕복 횟수를 추가로 줄임
  * 페이지의 접근성 트리에서 불필요한 정보를 덜어내 모델이 읽어야 할 문맥과 토큰 사용량을 줄임
  * README의 2배 속도 비교는 Browserbase에서 실행한 동일 스크립트와 클라우드 Playwright를 기준으로 함
## 토큰 효율과 브라우저 실행 구조

  * 접근성 트리의 하이브리드 가지치기로 에이전트에 필요한 페이지 문맥만 전달함
  * 브라우저 확장 프로그램으로 브라우저 옆에서 실행해 모든 동작의 왕복 지연을 줄임
  * WebMCP 로 웹페이지가 노출하는 도구를 발견하고 호출할 수 있음
  * 에이전트용 기능으로 심층 로케이터와 OTel 실행 추적을 지원함
    * 심층 로케이터는 중첩 iframe과 닫힌 Shadow DOM을 탐색함
    * 클립보드 지원과 일괄 명령도 제공함
## 로그인부터 구조화된 데이터 추출까지
  * 세션 유지를 통해 한 번 로그인한 상태를 다음 실행에서도 사용할 수 있음
    * 예제는 `userDataDir`에 쿠키를 보관하고 로그인 후 청구 페이지에서 청구서 번호, 금액, 납부 여부를 추출함
  * `observe` 는 자연어로 찾은 요소의 실제 선택자를 반환함
    * 로그인 예제는 반환된 선택자로 이메일과 비밀번호를 직접 입력하므로 자격 증명을 모델에 전달하지 않음
  * `act` 는 “로그인 버튼 클릭”, “청구 페이지 열기” 같은 자연어 지시를 수행함
    * `act`, `observe`, `extract`는 사이트가 바뀌면 작업 수행 방식을 갱신하며, 로그인 폼 재설계에도 자기 복구 기능을 적용함
  * `extract` 는 구조화된 데이터를 반환함
    * TypeScript 예제는 Zod, Python 예제는 Pydantic으로 스키마를 정의하고 검증된 데이터를 받음
    * Go 예제는 추출 결과를 Go 타입으로 디코딩함
## Browserbase 실행과 모델 및 캐시 관리
  * 같은 스크립트를 Browserbase 에 연결하면 동등한 Playwright 클라우드 브라우저 대비 2배 빠른 실행을 제공함
  * Model Gateway 를 사용하면 모델 제공자를 직접 연결할 필요가 없음
    * 모델 설정을 생략한 예제에서는 각 동작에 가장 저렴한 모델을 선택함
  * 서버 측 캐싱 으로 반복 동작을 캐시할 수 있음
    * 캐시를 활성화하면 동일한 호출은 Browserbase에서 반환하며 토큰을 소비하지 않음
  * 브라우저 실행 환경에 다음 기능이 함께 제공됨
    * Verified mode , 주거용 프록시 L59:     * 영구 컨텍스트 , 세션 녹화 L60:     * 세부 설정은 브라우저 구성 문서 에서 확인할 수 있음
## 코딩 에이전트 연결과 브라우저 없는 검색

  * 호스팅된 Browserbase MCP 서버 는 모든 MCP 클라이언트에 `navigate`, `act`, `observe`, `extract`를 제공함
    * 별도 설치나 로컬 브라우저가 필요 없으며, Claude Code, Cursor, Codex 등의 연결 예제를 제공함
  * Fetch 는 URL의 콘텐츠를 Markdown으로 가져오며, Search 는 빠르고 토큰 효율적인 웹 검색 결과를 제공함
