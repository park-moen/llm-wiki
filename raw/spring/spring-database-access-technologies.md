## H2와 schema

- Spring Boot 2.x 강의 환경은 H2 1.4.200, Spring Boot 3.x는 H2 2.1.214 이상을 안내한다.
- 실행: macOS/Linux `./h2.sh`, Windows `h2.bat`
- 최초 file 접속 예: `jdbc:h2:~/test`; 이후 TCP 접속: `jdbc:h2:tcp://localhost/~/test`
- 회원 table은 `id bigint generated by default as identity`, `name varchar(255)`, `primary key (id)`로 만든다.

## JDBC 설정

Gradle dependency:

```groovy
implementation 'org.springframework.boot:spring-boot-starter-jdbc'
runtimeOnly 'com.h2database:h2'
```

Datasource 예:

```properties
spring.datasource.url=jdbc:h2:tcp://localhost/~/test
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
```

순수 JDBC 구현은 `DataSource`, `Connection`, `PreparedStatement`, `ResultSet`과 exception·resource close를 직접 다룬다.

## 구현체 교체와 통합 테스트

- `SpringConfig`가 `MemberRepository` bean을 `MemoryMemberRepository`에서 `JdbcMemberRepository(dataSource)`로 바꾼다.
- Service가 interface에 의존하므로 application code 변경 없이 Repository 구현체를 교체한다. 이를 DI와 개방-폐쇄 원칙(OCP)의 예로 설명한다.
- `@SpringBootTest`는 Spring container와 함께 통합 test를 실행한다.
- test의 `@Transactional`은 각 test 종료 후 transaction을 rollback하여 DB 상태를 되돌린다. test가 아닌 application code에서는 transaction commit이 기본이다.

## JdbcTemplate

`JdbcTemplateMemberRepository`는 JDBC 반복 코드를 줄이지만 SQL은 직접 작성한다. `JdbcTemplate`은 `DataSource`를 받아 생성하며 Spring configuration에서 구현체를 교체한다.

## JPA

- JPA는 반복적인 SQL과 data mapping을 처리하는 ORM 표준 interface이고 Hibernate는 구현체다.
- Spring Boot JPA starter는 JDBC 관련 dependency도 포함한다.
- Entity는 `@Entity`, id는 `@Id`, identity 전략은 `@GeneratedValue(strategy = GenerationType.IDENTITY)`로 mapping한다.
- `JpaMemberRepository`는 `EntityManager`의 `persist`, `find`, JPQL query를 사용한다.
- JPA를 통한 data 변경은 transaction 안에서 실행해야 하므로 Service에 `@Transactional`을 적용한다.
- Spring Boot 3.0 이상에서는 `javax.persistence` 대신 `jakarta.persistence`를 사용한다. `javax.sql.DataSource`는 이 변경 대상이 아니다.

## Spring Data JPA

```java
public interface SpringDataJpaMemberRepository
        extends JpaRepository<Member, Long>, MemberRepository {
    Optional<Member> findByName(String name);
}
```

Spring Data JPA가 interface implementation을 자동 생성하고 Spring bean으로 등록한다. `JpaRepository`가 제공하는 CRUD와 paging 기능을 사용하며, interface method 이름으로 query를 만들 수 있다. 복잡한 동적 query는 Querydsl을, 필요하면 JdbcTemplate이나 native query를 함께 사용할 수 있다고 설명한다.
