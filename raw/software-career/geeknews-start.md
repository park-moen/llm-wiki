# GeekNews 시작하기

> Source: https://news.hada.io/start
> Collected: 2026-08-27
> Published: Unknown

GeekNews는 개발·기술·스타트업 소식이 매일 빠르게 올라오는 뉴스 서비스입니다.

좋은 링크와 좋은 댓글이 사용자들의 투표를 통해 더 잘 보이도록 운영됩니다.

최신 개발·기술·스타트업 소식을 읽을 수 있고, 개발, 소프트웨어, 제품, 오픈소스, 엔지니어링 문화, 스타트업, 기술 트렌드처럼 Geek들이 지적으로 관심을 가질 만한 주제가 잘 맞습니다.

GeekLists에서 제목을 누르면 뉴스의 원문 링크로 바로 이동합니다. 이는 원문 작성자와 출처를 존중하고, 내용을 먼저 원래 맥락에서 읽을 수 있도록 하기 위한 기본 방식입니다. GeekNews에 적힌 요약이나 댓글은 제목 아래 본문 요약 또는 댓글과 토론 링크에서 볼 수 있습니다.

놓치고 싶지 않은 글은 GeekNews Weekly로 받아볼 수 있습니다.
