# 클릭 한 번으로 테스트 45만 개 완료! 테스트 자동화 플랫폼 구축기

> Source: https://toss.im/slash-24/sessions/15
> Collected: 2026-08-16
> Published: 2024-09-12

토스페이먼츠의 Node.js 개발자가 Playwright 기반 테스트 자동화 플랫폼을 소개한 SLASH24 세션이다. 세션 설명은 매일 45만 개의 테스트를 처리하는 방법을 다룬다고 밝힌다.

공식 세션 페이지에서 발표 영상을 다시 볼 수 있으며, 같은 페이지에서 Data, Infra, Server, Frontend, DevOps, Android와 QA 등 다른 SLASH24 세션으로 이동할 수 있다.
