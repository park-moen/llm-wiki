# Jira 작업 항목 분할 크기에 관한 사수 피드백

> Source: 사용자가 대화에서 제공한 현업 회고 메모
> Collected: 2026-08-18
> Published: Unknown

아래 내용은 사수의 발언을 그대로 옮긴 직접 인용문이 아니라, 사용자가 피드백을 받은 뒤 회상하여 정리한 내용이다.

- Jira의 `TNSP-963` 에픽에서 각 스토리와 하위 작업을 너무 작은 단위로 나누었다는 의견을 사수에게 들었다.
- 사수는 `TNSP-1179`처럼 GitHub Issue 정도의 작은 작업 크기로 하위 작업을 나누면 관리가 힘들어질 수 있다고 설명했다.
- 하위 작업을 지나치게 잘게 나누는 대신 페이지 단위 정도로 나눠보는 것이 어떻겠느냐는 의견을 받았다.
- 사용자는 이 피드백을 기억하고 다음 작업 분할에 적용하고 싶다.
