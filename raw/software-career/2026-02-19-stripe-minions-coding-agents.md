# Minions: Stripe’s one-shot, end-to-end coding agents—Part 2

> Source: https://stripe.dev/authors/alistair-gray
> Collected: 2026-08-16
> Published: 2026-02-19

Stripe의 사내 coding agent인 Minions는 매주 천 건이 넘는 pull request가 merge되는 데 관여한다. Agent가 시작부터 끝까지 코드를 작성하지만 사람은 결과 코드를 review한다.

이 사례는 높은 수준의 구현 위임과 인간의 변경 승인·책임이 동시에 존재할 수 있음을 보여준다.
