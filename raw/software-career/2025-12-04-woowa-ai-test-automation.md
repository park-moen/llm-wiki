# AI와 함께하는 테스트 자동화: 플러그인 개발기

> Source: https://techblog.woowahan.com/24568/
> Collected: 2026-08-16
> Published: 2025-12-04

우아한형제들의 테스트 코드 생성 실험에서 첫 버전은 10개 클래스 모두 테스트를 생성했지만 컴파일 성공은 1/10, 수정 없이 실행 가능한 결과는 0/10이었다. 기존 테스트 손실, import 오류, 존재하지 않는 타입과 불완전한 커버리지도 발견됐다.

팀은 완성 코드를 AI가 전부 생성하는 방식 대신, 플러그인이 컴파일 가능한 템플릿과 테스트 대상을 결정하고 Amazon Q가 TODO 구현을 채우는 역할 분담으로 전환했다. 개선된 방식은 100개 테스트 중 97개 통과, 클래스당 작업 시간 70% 단축, 95% 컴파일 성공이라는 결과를 기록했다.

원문의 결론은 다음과 같다.

> “완벽한 자동화는 불가능하지만, 효율적인 보조는 가능하다”

개발자는 최종 판단과 검증을 담당한다.
